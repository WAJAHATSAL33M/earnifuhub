# EarnifyHub

Mobile-first React and Vite frontend preview. Run npm ci, then npm run dev. Run npm run build for a production bundle.

The preview includes the public homepage, account and recovery screens, and a navigable member area with plans, checkout, wallet, history, team and support. Forms use local demo state. No account, payment, file upload or support data is sent to a backend.

Vercel builds the site from this repository. The route rewrite supports opening inner pages directly.
